# Audi Connect for Home Assistant

Connect your Audi account and use supported vehicle status, charging, climate and access features through native Home Assistant entities.

Go to **Settings → Devices & Services → Add Integration → Audi Connect**. In regions using Auth0, open the displayed sign-in link, sign in and paste the complete localhost callback URL into the Home Assistant form. Never share the callback or credentials.

V2 remains the default. Builds that include experimental V3 offer capability discovery, trip history, optional EU Data Act enrichment and an optional Engineering Workbench. V3 is not required for ordinary use and is not yet a stable release.

See the [README](readme.md) for installation and current status, the [V2 reference](docs/V2_USER_GUIDE.md) for options and controls, and the [V3 guide](docs/V3_REVIEW.md) for experimental testing and rollback.
